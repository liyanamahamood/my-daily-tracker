# My Daily Bloom

A personal productivity web app designed to make everyday routines more organised, mindful and meaningful.

## About the Project

My Daily Bloom is a simple and user-friendly web application that helps users organise daily tasks, track prayer routines, maintain a journal and find daily inspiration.

## Features

- **Daily Dashboard:** View the date, greeting and daily progress.
- **Task Management:** Add and manage daily tasks.
- **Prayer Tracker:** Keep track of five daily prayers.
- **Personal Journal:** Record thoughts, gratitude and moods.
- **Daily Inspiration:** Read motivational quotes and Quran verses.
- **Journal Archive:** Revisit previous journal entries.
- **Data Persistence:** Save personal entries using browser local storage.
- **Progress Tracking:** Monitor daily task completion.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Progressive Web App (PWA)
